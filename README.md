# SDVIG

Чёрно-белый музыкальный плеер-агрегатор для Android, Windows и Linux.

## Что работает (v0.2)
- Единый поиск: YouTube (неофициально), Audius (полные треки), Apple Music и Deezer (превью 30 с)
- Реальное воспроизведение (media_kit / libmpv), эквалайзер, скорость
- Очередь, любимое, история, локальные плейлисты без аккаунта
- Гибкая кастомизация оформления

## В планах
VK, Яндекс Музыка, SoundCloud, Spotify (метаданные), скачивание, фоновое воспроизведение и уведомление, тексты песен.

## Сборка
Готовые файлы собираются автоматически во вкладке **Actions** (artifacts).
Linux: для запуска нужен `libmpv` (`sudo apt install libmpv-dev mpv`).
