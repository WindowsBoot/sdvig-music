# SDVIG

Чёрно-белый музыкальный плеер-агрегатор для Android, Windows и Linux.

- Единый поиск по SoundCloud, YouTube Music, Яндекс Музыке, VK и Spotify
- Локальные плейлисты без аккаунта
- Гибкая кастомизация оформления и эквалайзер

**Статус:** v0.1 - интерфейс и архитектура провайдеров (демо-данные).

## Сборка
Готовые файлы собираются автоматически во вкладке **Actions** (artifacts).
Локально: `flutter create --platforms=android,windows,linux .` и `flutter run`.
